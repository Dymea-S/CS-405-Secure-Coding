# CS-405-Secure-Coding
This repository contains my coursework and projects for CS 405: Secure Coding at Southern New Hampshire University (SNHU). The projects focus on developing secure C/C++ applications, identifying vulnerabilities, applying secure coding standards, and implementing security best practices throughout the software development lifecycle. 

Topics covered include:

<h5>
- 🔐 Secure coding principles and best practices  
  
- 🛡️ Defense in depth and zero trust
- 🔍 Static code analysis using Cppcheck and Visual Studio
- 🧪 C++ unit testing with Google Test
- ⚠️ Vulnerability and risk assessment  
- 🔒 Encryption and data protection  
- 👤 Authentication, Authorization, and Accounting (Triple-A)  
- ⚙️ DevSecOps and security automation  
- 💻 C++ exception handling and secure programming  
- 📋 Security policies based on SEI CERT C++ standards
</h5>

The repository demonstrates my progression in identifying security vulnerabilities, evaluating risks, developing secure code, and integrating security throughout the software development process.
