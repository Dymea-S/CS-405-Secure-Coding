# CS-405-Secure-Coding
This repository contains my coursework and projects for CS 405: Secure Coding at Southern New Hampshire University (SNHU). The projects focus on developing secure C/C++ applications, identifying vulnerabilities, applying secure coding standards, and implementing security best practices throughout the software development lifecycle. 

Topics covered include:

- 🔐 Secure coding principles and best practices</h5>  
- 🛡️ Defense in depth and zero trust
- 🔍 Static code analysis using Cppcheck and Visual Studio
- 🧪 C++ unit testing with Google Test
- ⚠️ Vulnerability and risk assessment  
- 🔒 Encryption and data protection  
- 👤 Authentication, Authorization, and Accounting (Triple-A)  
- ⚙️ DevSecOps and security automation  
- 💻 C++ exception handling and secure programming  
- 📋 Security policies based on SEI CERT C++ standards
</h5>

The repository demonstrates my progression in identifying security vulnerabilities, evaluating risks, developing secure code, and integrating security throughout the software development process.

**Projects**
Module Five – Static Code Analysis

The Static Code Analysis project demonstrates how automated analysis tools can identify potential coding defects and vulnerabilities. The project uses Cppcheck and Visual Studio's built-in code analysis to examine intentionally questionable C++ code and compare the warnings produced by each tool.

The project focuses on identifying issues such as:

- Uninitialized variables
- Potential buffer overflows
- Incorrect operators
- Exception-handling issues
- Other potential coding and security weaknesses
- Unit Testing

The unit testing projects use the Google Test framework to test C++ functionality. The tests include both positive and negative test cases to verify expected behavior and ensure that errors and exceptions are handled appropriately.

**SQL Injection**

The SQL injection project demonstrates how an application can be vulnerable to manipulated SQL queries and how defensive coding techniques can be used to detect and prevent injection attempts.

**Exception Handling**

The exception-handling project demonstrates standard C++ exception handling, including try blocks, standard exceptions, custom exceptions, and catch handlers.

**Encryption**

The encryption project demonstrates XOR-based encryption, reading data from text files, saving encrypted and decrypted data, and handling file input/output using C++.

**Green Pace Security Policy**

The Green Pace Security Policy project combines secure coding standards, risk assessment, automation, encryption, Triple-A security, and defense in depth into a comprehensive security policy. The project focuses on integrating security into the development process through a DevSecOps approach.

**Security Approach**

A major theme throughout this repository is that security should not be left until the end of development. Security should be incorporated throughout the software development lifecycle through secure coding standards, automated analysis, unit testing, vulnerability assessment, and continuous monitoring.

The projects demonstrate how multiple security controls can work together as defense in depth, providing multiple layers of protection rather than relying on a single security mechanism.
